# 2048

Unity로 2048을 따라 만들며 구조를 익히는 학습 프로젝트입니다. 이동과 병합 규칙, 타일 애니메이션, 게임 오버 판정을 코드로 직접 따라 쳐 보면서 보드 게임의 상태 관리를 공부했습니다.

| 항목 | 내용 |
| --- | --- |
| 엔진 | Unity 6000.0.3f1 (UGUI) |
| 언어 | C# |
| 조작 | `WASD` 또는 방향키 |
| 코드 위치 | `Assets/Scripts` |

## 구조

| 스크립트 | 역할 |
| --- | --- |
| `TileGrid`, `TileRow`, `TileCell` | 4×4 칸을 관리합니다. 좌표로 칸을 찾고, 방향에 따라 인접 칸을 돌려주며, 빈 칸 중 하나를 무작위로 고릅니다. |
| `Tile`, `TileState` | 타일 하나의 상태(숫자, 배경색, 글자색)를 `ScriptableObject`(`TileState`)로 두고 타일은 상태만 바꿉니다. 이동은 `Lerp`로 0.1초 동안 움직입니다. |
| `TileBoard` | 입력을 받아 타일을 움직이고 합칩니다. 방향마다 칸을 훑는 순서를 달리해서, 한 방향 코드(`Move`)로 네 방향을 처리합니다. |
| `GameManager` | 점수, 최고 점수(`PlayerPrefs`), 새 게임, 게임 오버 화면 페이드를 맡습니다. |

## 규칙 구현에서 신경 쓴 부분

- **한 번에 한 번만 합치기**: 이번 이동에서 이미 합쳐진 타일은 `locked`로 표시해서, 한 입력으로 2-2-4가 8로 연달아 합쳐지지 않게 했습니다. 애니메이션이 끝나면(0.1초 뒤) 잠금을 풉니다.
- **이동 중 입력 막기**: 애니메이션이 도는 동안은 입력을 받지 않습니다.
- **이동이 있었을 때만 새 타일 생성**: 아무것도 움직이지 않았다면 타일을 새로 만들지 않습니다.
- **게임 오버 판정**: 보드가 가득 찼고 상하좌우 어느 인접 칸과도 합칠 수 없을 때만 게임 오버입니다.
